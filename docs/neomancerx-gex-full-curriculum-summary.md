## 1. 全书立场与能力边界

### 1.1 三条总立场（首页反复强调）

1. **墙位 ≠ 支撑/阻力线**。墙是做市商对冲最密的价位；多数时候行为像 S/R，**一旦真破，角色会反转**。  
2. **统计口径不可混用**。换「墙位权重 / 到期窗口 / 计算口径」后，**所有关键位必须重读**。  
3. **指标给的是概率环境，不是方向预言**：回答「偏震荡还是偏趋势」，不回答「明天涨还是跌」。

### 1.2 能回答的 5 个问题 / 不能回答的 3 个

| 能回答 | 不能回答 |
|--------|----------|
| ① 今日偏震荡还是偏趋势（价相对 0Γ）——书中称「最有价值的输出」 | ① 方向（涨/跌） |
| ② 今日值得盯的价位（墙 + Gamma Kings 等） | ② 仓位大小与止损距离（取决于账户与风险承受） |
| ③ 结构在加强还是变松 | ③ 在极薄期权链上给出可靠读数 |
| ④ 期权异动（量/OI、大单、OFI 等） | |
| ⑤ 概率意义上的目标/区间（EM） | |

**正确姿势**：先体制、后策略；关键位是「观察位」不是「必反转位」；先核数据可信再看数；**当过滤器，不当扳机**（「今天不宜追」优于「现在买入」）。5-10 另列三类不确定性：模型（GEX 由已嵌预期的期权价反推）、数据（不全/延迟/低覆盖——显示≠治愈）、市场（做市商策略与流动性会变——「快照不是定律」）。

## 3. 核心概念精炼

### 3.1 Gamma 与 GEX

- **Delta = 速度，Gamma = 加速度**。同执行价同到期的 Call/Put Gamma 本身同号；符号来自做市商净多/净空。  
- **正 Gamma（MM 净多）**：涨则卖、跌则买 → 对冲逆着价格 → **吸住/钉住** → 偏震荡。  
- **负 Gamma（MM 净空）**：对冲顺着价格 → **推开** → 偏趋势。负 Gamma **≠ 看空**——它是双向放大，「做错更贵」。  
- **Γ ∝ 1/√T**：临近到期 Gamma 极陡 → 0DTE「看起来最清晰，其实最不确定」。  
- **GEX(K) ≈ Gamma(K) × OI × 合约乘数 × 标的价**；Call 正、Put 负；分侧取墙，勿用净 GEX 自推墙位。

### 3.2 三个关键位：Call Wall / Put Wall / Zero Gamma

- **Call Wall**：Call 侧最大正 GEX 行权价（通常在价上方）。  
- **Put Wall**：Put 侧最大 |负| GEX 行权价（通常在价下方）。  
- **Zero Gamma**：净 GEX 变号处（常在行权价之间）——**体制开关，不是支撑位**。  
- 一起读「价相对三者的位置」：价在墙间且在 0Γ 上方 → 正 Gamma 震荡；价在 0Γ 下且下墙很远 → 负 Gamma 趋势，止损优先。  
- **跌破 0Γ ≠ 自动做空**；整份盘前计划边界要重算、敞口要收缩。

### 3.3 墙的四态与角色反转

| 状态 | 含义 | 计划 |
|------|------|------|
| 未到 | 仅参考 | 不变 |
| 触及 | **观察窗**，不预设结果 | 不变 |
| 假破 | 快速收回，墙更可信 | 不变 |
| 真破 | 留在墙外 | **角色反转，必须重画计划** |

真假破需 **≥3/4 维**一致：墙外停留时间、收盘位置、结构事件日志（最强——多帧确认才入账）、量柱新厚行权价。  
**角色反转（书中最有价值也最易丢掉的规则）**：破 Put 墙 → 转压力；破 Call 墙 → 转支撑。口诀：**墙在头上偏空，墙在脚下偏多**（与 Call/Put 名称无关）。方向面板在价距关键位约 **0.05%** 内显示「临界：方向未定」。

### 3.4 正 / 负 Gamma 日个性

- **正 Gamma**：影线多、假破多、区间重复；关键词 **回归而非延续**；追涨杀跌易卡在短期极值。  
- **负 Gamma**：一出区间易加速、反弹短、破位不轻易回；关键词 **延续而非回归**；禁摊平、先写失效位、仓位通常要更小。  
- 上穿/收回并站稳 0Γ（且日志确认）常是「结构修复」的第一信号。

### 3.5 剩余 EM、已耗%、结构止损与 R:R

- 两套尺子：**全日期望**（开盘定、管全天计划）与 **剩余期望**（此刻→收盘，盘中计划必须用剩余）。  
- ±1σ ≈ **约 68% 概率区间，不是天花板**（约 1/3 交易日会超出）。  
- **已耗 %**：&lt;40% 仍有空间；**&gt;70% 今日波动大半已实现，追单性价比差**。  
- **目标** = 剩余期望边；**止损** = 结构失效位（0Γ 或刚破墙）；R:R = 目标距 ÷ 止损距；**明显 &lt;1 则跳过**。  
- 纪律：**先结构止损 → 再验 R:R → 不够就跳过**；结构止损太远则 **减仓或不做，绝不把止损往近处拖**。全日期望会系统性高估 R:R。

### 3.6 Gamma Kings、多窗口共振

- 每到期一行：K+（最强正 Gamma，偏吸住）/ K-（最强负 Gamma，偏推开）/ gate（门卫）/ hot（今日量最集中）。盘中先读 **金色 0DTE 行**。  
- Kings 是**位不是方向、更不是目标价**；跨到期共振最硬；hot∩king 最有读头。  
- **多窗口共振（含金量最高的一类信号）**：0DTE / 近周 / 近月 / 远月切换记录墙，**≥2/4 同价即标记**；共振抬「值得盯」的置信，**不保证不破**。近端一致远端不一致 → 问「明天还在吗」。

### 3.7 MNQ → NQ 代理链（对本项目最关键）

- 微合约自有期权链长期极薄（书中实测：整条微链约 450 合约仅 2 个有 OI）→ 自算墙可偏价数个百分点且无交易意义。  
- **代理链默认开**：微链不可用（0 合约 / 无 OI / 覆盖率 &lt;5%）时切到**同交割月标准合约期权**（MNQ→NQ），状态行会标注；**乘数取链上合约的乘数（NQ），不是图表合约（MNQ）**。  
- 实务建议：**NQ 图读结构，MNQ 图执行**；跨品种 GEX 绝对值不可比。

### 3.8 预过滤否决、数据日 / 到期周、五维盘前分

**预过滤（任一项失败 → 今日不做 GEX 计划）**：数据是否「实时」；OI 覆盖是否出现「墙位不可信」；三关键位是否存在；口径与到期窗口是否自洽；MNQ 场景下代理链是否可用。  

**数据日（CPI/FOMC/非农）**：发布瞬间 IV 跳 → 读数短暂作废 → 约 30 分钟假破高峰 → 1–2 小时后新结构渐可信。核心问题不是「数据好坏」，而是**当前体制能否消化冲击**。  

**到期周 / 结算日**：仅靠本周 OI 支撑的墙结算后可能无人防守；结算**最后一小时不要执行早盘计划**，重读边界；Pin/Magnet = 观察位不是目标；强度 ≈ 集中度 × 剩余时间 × 链厚度（乘法）。  

**五维盘前分（5-09，一日一次）**：体制清晰度 / 关键位硬度（多窗口共振）/ 空间充足度 / 结构一致性 / 扳机确认（日志）。8–10 全开计划 · 4–7 收缩 · 0–3 **不计划也是决策**。分数只管计划细度，**不管方向与仓位**。

- 做市商赚点差不赌方向 → 对冲是**流程不是观点**；期权会反馈进价格。新闻点火，**Gamma 结构决定火烧多大**。

- 五分钟上手：先看状态行可信 → 体制 → 价相对三线 → 分布 → 方向/告警。**先定性，再看数。**

### 4.3 本地部署与参数（2-01～2-11）

- 四个静默坑：混口径、说墙不说窗口、窗口太窄以为坏了、未查覆盖率就交易墙。十秒自问：**什么口径？什么窗口？数据够不够厚？**

### 4.4 看懂面板（3-01～3-16）

- **信息卡**：体制行（正/负/未知）；未知时不做方向判断。  
- **方向面板**：墙态与偏多/偏空；0Γ 行只显示偏震荡/偏趋势，永不直接多空。  
- **分布三列**（Gamma/量/OI 各自归一）：三柱同厚最硬；仅量厚 = 今日新建仓最值得注意。  
- **热图**（时间×价）vs **到期矩阵**（价×到期）：近远端中心分裂 = 结构分裂，价格易在两中心间震荡。  
- **到期梯子**：GEX 列为净值（双厚可净≈0）；纵向扫 CW/PW 做共振；净正 GEX ≠ 看多。  
- **G-Scan**：重定价 0Γ vs 静态 0Γ 的差 = 地形陡度；差大时勿死押震荡/趋势日。  
- **EM / OFI / Pin / 异动 / Theta / 四维条 / Skew / 告警**：见上节核心；告警 P1（墙穿越、Gamma 翻转等）才强制停手重读三边界；结构事件日志仅交易视图、多帧确认。

### 4.5 市场实战（4-01～4-12）

- **盘前六步（顺序固定）**：数据可信 → 体制 → 三关键位 → 空间（剩余 EM）→ 硬度（分布+梯子+矩阵）→ 写下三边界（上沿/下沿/**失效位=0Γ**）。「没有失效位的计划不是计划。」

### 4.6 进阶精通（5-01～5-10）

## 5. 对 MNQ OPF 八路径过滤的含义（过滤器，不是扳机）

本仓库当前生效为四个家族、八条路径（ObservationConfirm ×2、Breakaway ×2、FailureReverse ×2、SignificantZoneFirstTouch 多/空）。GEX 在书中与本仓库冻结边界上的定位一致：**体制 / 空间 / 墙态 / 日历门禁**，不替代 Zone 几何与路径扳机。

| 主题 | 映射到 OPF |
|------|------------|
| 预过滤否决 | Ready + 实时 + 覆盖 + 三关键位 + **NQ 代理链**；不过则今日 GEX 不参与加减分（交易可按旧逻辑提示） |
| 正 Gamma | 假破/回归环境 → 更贴 OC、显著区首触「触及」观察；Breakaway Short 更应 Skip |
| 负 Gamma | 趋势加速 → 半仓/宽止损更谨慎；WideStop 路径更易被扫 |
