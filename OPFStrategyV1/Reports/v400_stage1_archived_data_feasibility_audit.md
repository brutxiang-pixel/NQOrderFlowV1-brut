## 课程概念的可行性裁决

| 概念 | 当前证据 | 裁决 |
|---|---|---|
| Zone 远近 | Zone 边界、Entry、决策时间均可严格连接 | 可做零成本单变量审计 |
| 当前触及时的 Delta / 价格响应 | ZoneTouch Delta、价格变化、Delta速度与逐笔边界完整 | 仅可定义当前触及状态 |
| POC 迁移 / 当前成交密度 | 三根 POC、区内/区外量与密度存在 | 可做描述性字段审计 |
| 证伪点 | 缺少 Zone 出生时的同口径主动成交签名 | 不可定义，须新采集 |
| 燃料 / 被套成交代理 | 当前 `ZoneVolume` 是决策前窗口密度，不是 Zone 出生到失效的累积账本 | 不可定义，须新采集 |
| 二/三次真实测试 | 24 个 `zones.csv` 共 945 条记录，全部 `TouchCount=0`；候选重复不等于真实触及 | 不可定义，须新采集 |
| 吸收序列 | 仅有 30/60 秒汇总，不含连续跨 Bar 阶段序列 | 不可定义，须新采集 |
| B/P Delta 子类 | 无逐价格层成交量分布或形态参数 | 不可定义，须新采集 |
| 两次速度减弱 | 有 30/60 秒计数，缺事件频率序列 | 不可定义，须新采集 |
| 三重共振 | 依赖上述未定义的原子事件 | 禁止提前组合 |

## 结论与 V4 阶段 2 输入

1. 现有归档数据可立即支持：Zone 远近、当前触及 Delta/价格响应、POC 迁移和成交密度的**字段审计**。
2. 它不支持将课程中的“燃料、证伪、吸收、二三次测试、B/P、两次减速”伪装为可回测字段；强行事后推断会引入生命周期缺失和未来信息。
3. V4 阶段 2 的最小 Data Only 采集器必须围绕 `ZoneID` 从出生到失效保存事件账本：出生签名、每次真实触及、突破/失效、累计主动成交代理、价格推进与逐笔边界。DOM 和热图仍永久排除。
4. 在全量 Actual Replay 完成和基线固化前，不实施阶段 2，不编译 DLL，不安排新 Replay。
