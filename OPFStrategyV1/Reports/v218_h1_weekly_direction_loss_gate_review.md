# v2.18 H1周度方向损失门离线研究

日期：2026-07-26

## 最终结论

UTC时段门正式否决。本轮重新从可部署、入场时可知且具有状态因果的规则出发，共模拟154个策略组合，冻结一个离线候选：

> 以Snapshot交易日所属ISO周为统计周；当本周已实现账户Net或本周已实现Long方向Net任一达到`-$500`及以下时，本周剩余时间禁止所有新Long订单。Short、Breakaway、现有持仓管理、日损和其他约束继续正常运行；下一个新周自动复位。

候选达到H1盈利目标并在两轮7月压力样本中显著改善，但仍属于离线筛选结果。当前未修改DLL、未编译、未清日志、未进入Smoke。

## 为什么放弃静态切片

- H1的`ObservationConfirm_WideStop1_5R Long`在全部Regime、质量和风险分箱中总体为正，7月却几乎整体转负。
- 因此固定UTC时刻、固定质量阈值、固定风险上限都无法解释这种跨月状态切换；它们只是在已查看样本上切分结果。
- 之前的约束扫描和20点风险门也证明，静态删除会触发替代链，局部改善不能代表组合改善。
- 新规则不预测某个时段必亏，而是在Long侧已经用本周真实已实现损益证明失效后停止继续增加Long风险，Short核心路径仍可恢复账户。

## 研究范围

固定基线：

- `OPF_RESEARCH_2.18 / ACTUAL_EXEC_2.43`
- 3手、每日15笔正常交易、日损`-$250`
- 同向G2第二槽、并发初始风险`$300`
- 当前入场、退出、OCO、Globex和生命周期规则不变
- H1 122日与7月两轮基线均由修复后的模拟器精确复刻

模拟变量：

- 第二槽需第一槽达到0.75R/1R/1.5R后才能进入
- Breakaway Short第二槽G2豁免
- Long WideStop日内连亏暂停
- 周内账户损失、Long方向损失、Long WideStop损失三种触发指标
- 触发后暂停Long WideStop、全部Long、第二槽或组合动作
- 周损阈值`-$150`至`-$700`及重点区间细扫

共154个策略组合、462个“组合×样本”结果。第一槽进展门、Breakaway额外豁免和日内Long WideStop连亏暂停均未形成跨期优势。

## 精确定义

1. 统计对象只包含已实现账户交易，不读取浮盈、未来Bar或未完成交易结果。
2. `WeeklyAccountNet`包括Normal、Abnormal和Quarantine的真实账户Net及手续费。
3. `WeeklyLongNet`只累计已平仓Long订单的账户Net及手续费。
4. 两者任一`<= -$500`后，禁止本周剩余的新Long订单；已持有Long继续按原OCO管理，不强平。
5. Short完全保留，包括Breakaway Short；每日15笔、日损`-$250`和并发风险`$300`继续生效。
6. 周界使用策略交易日的ISO周，周一新Snapshot复位；不得使用本地墙钟或UTC小时切点。
7. 错误/隔离订单不计15笔正常交易上限，但其真实账户Net必须计入周损状态。
