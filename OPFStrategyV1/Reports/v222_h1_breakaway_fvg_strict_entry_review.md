# v2.22 BreakawayFvg Short 严格入场离线研究

## 范围与口径

- 基线：v2.21 H1，878笔、Gross `+$26,435.12`、Net `+$23,274.32`、PF `1.7062`。
- 固定组合约束：3手、双槽同向G2、并发风险`$300`、15笔、日损`-$250`、周Long门`-$500`。
- 仅收紧 Primary `BreakawayFvg Short`；不改变第二槽、仓位、退出、时间门或 Actual 逻辑。
- 79组预设静态门禁：`SetupQualityScore`最小值 {88,90,92,95}、`ExactRisk`最小值 {8,10,12}、`RegimeScore`最小值 {70,80,90} 的单项和交叉组合。三个字段均在入场时可知。

## 结果

最优候选为 `SetupQualityScore >= 88 && ExactRisk >= 12`：

| 指标 | 基线 | 候选 | 变化 |
|---|---:|---:|---:|
| H1交易数 | 878 | 867 | -11 |
| H1 Gross | +$26,435.12 | +$26,825.12 | +$390.00 |
| H1 Net | +$23,274.32 | +$23,703.92 | +$429.60 |
| PF | 1.7062 | 1.7244 | +0.0182 |
| 最差周 | -$665.10 | -$665.10 | 持平 |
| MaxDD | $2,121.10 | $2,112.90 | 改善$8.20 |
| 7月 Net | +$11.52 | +$11.52 | 持平 |

六个月逐月Net变化为 `-$2.90 / +$64.70 / +$92.80 / +$9.10 / +$184.70 / +$81.20`：5/6个月为正，唯一负值接近零。`RegimeScore >= 70`与该候选结果完全相同，说明它没有提供独立筛选信息。

反例同样重要：质量提升至90后，H1仅增加`+$86.60`，且7月恶化`-$215.80`。因此不能把“更高质量阈值”误判为稳健方向。

## 判定

本轮没有进入Smoke候选。最优门禁虽具备跨月方向一致性，但未达到本轮预注册的 `H1 Net 增益 >= +$500` 研究筛选线；79组中没有任何组合同时超过该线、维持PF/回撤约束，并且不伤害7月。

这条结果比Retest窗口研究更有价值：BreakawayFvg Short存在可重复的严格化信号，但当前可用的三个入场特征只够带来约`+$430`，不足以支撑DLL改版或Replay成本。
