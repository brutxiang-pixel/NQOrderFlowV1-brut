# v2.09 执行口径校准评审

日期：2026-07-25

结论：离线执行口径已明显变得更忠实，但五日交易集合复刻仍未达到冻结的 `90%` 门槛；H1 Gross 也不再达到 `$20,000`。因此本轮不编译 DLL、不清日志、不进入新 Smoke、不打 Tag。

## 本轮修正

- Deferred 激活候选改为同一父交易下的候选集合，并使用实时 Shadow tracker 判断候选是否仍存活；不再用固定 12-Bar 代替候选生命周期。
- Deferred 激活检查移动到闭合 M5 处理之后，消除已确认的系统性晚一根 M5。
- ZoneBirth 全部按 Rich M5 重新计算真实可部署的 `2 Base + 1 Runner`：Base `2.5R`、Runner `4R`、Base TP 后 Runner 从下一根 M5 起保本、同柱 StopFirst。
- Core 同时检查计划风险与成交后 FilledRisk；任一落入 `(13.25,16]` 均不进入正常策略账本。
- 执行账本中 `ExitTime <= EntryTime` 的 Historical Replay 塌缩记录不再当作零占用；回退到对应 Shadow 精确生命周期。本轮 H1 共回退 347 笔。
- Deferred 激活时用最近 20 根 Rich M5 重算可复刻的最近结构 RR 门，避免把明显会被 Actual 再门禁拒绝的候选计为成交。
- 原来标记为 ActiveTrade 阻塞的候选也重新进入时间轴；若新组合链在该时刻已经空仓，可作为普通候选执行，避免固定 Core/Released/Deferred lane 漏掉替代交易。
