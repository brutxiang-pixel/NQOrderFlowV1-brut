# OPF_INTRADAY_2.1 图表显示整理

仅修改显示及版本号，不改候选、门禁、下单、SL/TP、保护单或飞书逻辑。

- 默认左上角紧凑HUD：版本/产品/模式、执行门禁、日交易数/净收益/持仓、Regime/区域/槽位、ES状态/年龄/M5响应、CW/PW/EM、最多两笔活动订单价格。宽度最多390px，高度按主图28%限制，长行省略，不横向扩张。门禁READY绿色，等待橙色，异常提醒红色。
- 策略设置`OPF HUD > Show Detailed Diagnostics`默认关闭，打开查看详细诊断；宽度最多520px、高度主图45%，超出部分提示查日志。完整诊断仍在日志中，不通过继续增高面板显示。
- `Show Historical Order Details`默认关闭，已平仓订单仅绘制细连接线及入场/退出短标记，不绘制历史ENTRY/SL/TP/EXIT文本。原Actual Max Visible Orders和Lookback仍控制历史数量/范围。
- 活动订单优先绘制，不被历史订单挤出；活动SL/TP等标签右侧排布并避让已占区域，超出边界或无法放置时省略文字，价格线仍在。可打开历史详情临时复盘，也使用避让布局。
- 人工决策卡排在HUD下方，避免二者叠加；图表空间不足时不向图外绘制卡片。
- 仍需重启ATAS，在真实窗口检查DPI/缩放效果；构建检查不等于实际渲染验收。未自动重启或操作运行中的策略。

验收：Release零警告零错误；保护单与订单回归保持通过。旧DLL备份后部署，旧日志保留。
